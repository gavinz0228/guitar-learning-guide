💎 CAGED 系统

用五个基础和弦形状覆盖整个指板

CAGED系统是吉他手必学的核心概念。它将吉他指板划分为五个区域，每个区域对应一种开放和弦形状。掌握这个系统，你就能在指板上任意位置按出任何和弦。

C Shape - C Major (根音在3品A音)
C形状基于开放C和弦，移动到第3品时形成C和弦（根音在5弦3品A音，实际音高为C）。 这是CAGED系统中最高位置的形状，常用于连接A形状。

🧠 Shell Voicing

精简和弦的高效按法 - 只用3个音构建完整和弦

Shell Voicing是用最少的音构成最完整的和弦意图。它通常只使用根音、3音和7音，让你在紧凑的把位中快速切换和弦。这是爵士乐和伴奏中最常用的技巧。

Cm7 Shell Voicing

Cm7b5 Shell Voicing
