理解 Shell Voicing 和 CAGED 系统的核心概念

🧠 什么是 Shell Voicing？

Shell Voicing（贝壳和弦）是一种精简的和弦按法，只使用和弦中最关键的3个音：根音（Root）、3音、7音。它省略了5音，但保留了和弦的核心色彩和功能。

例如 Cmaj7 和弦的音是 C-E-G-B（根-三-五-七），Shell Voicing 只按 C-E-B（根-三-七），省略了五音 G。这样的好处是：

  • 指法简单，容易快速切换和弦
  • 给其他乐器或声部留出空间
  • 在伴奏中常用，特别是爵士乐
  • 可以在指板上快速平移到不同把位

和弦类型与组成

例：C-E-B

根 + 3音 + ♭7音

根 + ♭3音 + ♭5音 + ♭7音

💎 什么是 CAGED 系统？

CAGED 系统是吉他手必须掌握的核心概念。它利用五个开放和弦形状（C、A、G、E、D），将指板划分为五个区域，让你在任何位置都能按出同一个和弦。

五个形状的特点：

  • C形状：根音在5弦，手指排列成C形
  • A形状：根音在5弦，需要横按，手指排列成A形
  • G形状：根音在6弦，跨度较大的按法
  • E形状：根音在6弦，需要横按，最常用的形状
  • D形状：根音在4弦，高音区形状

使用方法：选择一个和弦名（如 G），然后查找这个音在各个形状中的位置。例如 G 和弦可以用 E形状（根音在6弦3品）、A形状（根音在5弦10品）等按出。

💎 CAGED 系统

用五个基础和弦形状覆盖整个指板

CAGED系统是吉他手必学的核心概念。它将吉他指板划分为五个区域，每个区域对应一种开放和弦形状。掌握这个系统，你就能在指板上任意位置按出任何和弦。
